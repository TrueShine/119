# 119 화재 데이터 대시보드

소방청 화재현황(2024–2025), 강원 소방용수시설, 주민등록 인구 데이터로 만든 정적 대시보드.

- 강원 소방 취약지도 · 골든타임 · 화재 원인 달력 · 우리 동네 리포트 · 연도 비교

## 구성
- `build.py` — 원자료 CSV를 집계해 `data.js` 생성 (`python3 build.py`, CSV는 `~/Downloads`에서 읽음)
- `index.html` + `data.js` — 서버 없이 동작하는 정적 사이트
